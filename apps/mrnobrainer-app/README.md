## MRnObrainer desktop app

This is the Tauri desktop app that powers the MRnObrainer overlay, timeline, onboarding, and release bundle.

- End-user install: use the [GitHub Releases page](https://github.com/CodingLikeCoking/MRnObrainer/releases)
- Main product overview and non-technical setup: see the [repo README](../../README.md)
- Local development:

```bash
cd apps/mrnobrainer-app
bun install
bun dev
```

If you are helping a non-technical friend test the desktop build, use the GitHub Releases DMG path in the repo root `README.md` rather than asking them to run Bun or Cargo locally.
